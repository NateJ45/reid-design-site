# Routes summary

Loaded when you touch `src/pages/`. Moved verbatim from the old CLAUDE.md (2026-10-03 split).

## Routes summary

| Path                 | Source                             | Notes                                                                                                                                                                                                                                     |
| -------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`                  | `src/pages/index.astro`            | Home page singleton from Sanity                                                                                                                                                                                                           |
| `/about`             | `src/pages/about.astro`            | About page singleton; ends with the Kind words wall (every testimonial not hidden, newest first, 2026-09-30)                                                                                                                              |
| `/process`           | `src/pages/process.astro`          | Process page + steps + filtered FAQs                                                                                                                                                                                                      |
| `/services`          | `src/pages/services.astro`         | Services page + service collection                                                                                                                                                                                                        |
| `/faq`               | `src/pages/faq.astro`              | FAQ page + faqItem collection grouped by category                                                                                                                                                                                         |
| `/contact`           | `src/pages/contact.astro`          | Contact page + Web3Forms form + Calendly embed + Instagram feed (renders nothing without a token)                                                                                                                                         |
| `/portfolio`         | `src/pages/portfolio/index.astro`  | Project grid with Room × Style filter chips                                                                                                                                                                                               |
| `/portfolio/[slug]`  | `src/pages/portfolio/[slug].astro` | Project detail: hero + meta band + intro story + before/after + gallery + sticky chip                                                                                                                                                     |
| `/e-design`          | `src/pages/e-design.astro`         | E-Design offering: intro + how-it-works + what's-included + pricing tiers + FAQ refs + final CTA. Coming-soon state when `eDesignPage` doc absent. CTAs route to `/contact?type=e-design`                                                 |
| `/privacy`           | `src/pages/privacy.astro`          | Privacy policy from `privacyPage` singleton, with a plain-voice static fallback when the doc is absent                                                                                                                                    |
| `/[slug]`            | `src/pages/[slug].astro`           | Custom pages Staci builds herself in the page builder (the `page` doc type). One static page per published doc; reserved slugs are blocked at schema + getStaticPaths. Renders via `SectionRenderer`. Surfaced in nav via `getNavPages()` |
| `/sitemap-index.xml` | `@astrojs/sitemap` (auto)          | Production sitemap. Filters out `/studio`, `/preview`, and every route of a section switched off in Sanity (`isHiddenSectionPath`, read at build time in `astro.config.mjs`)                                                              |
| `/search`            | `src/pages/search.astro`           | Site search over the Pagefind index (built by `postbuild`). `noindex`, out of the sitemap, in `tests/routes.ts`. Reached from the footer's base row (the header search icon went with the 2026-09-30 chrome) and the 404 box; reads `?q=` |
| `/404`               | `src/pages/404.astro`              | Custom 404, "This room is still empty" (2026-10-03: the concept room's empty frame, a line-drawn armchair, a deck index of four pages, a plain search box that hands off to `/search`)                                                    |

**Removed 2026-09-30 (never launched):** `/journal` (+ `/journal/[slug]`, `/journal/rss.xml`), `/shop`, `/quiz`, `/calculator`, `/guides` (+ `/guides/[slug]`), `/press`, `/gift-certificates` and `/resources`, with their Sanity types (journalEntry, journalCategory, journalPage, shopItem, shopCollection, shopPage, styleQuiz, budgetCalculator, leadMagnet, pressItem, pressPage, giftPage, resourcesPage), their components, and the footer newsletter signup (`NewsletterSignup.tsx`, `src/lib/subscribe.ts`). Their existing documents were left in the dataset untouched; only the types left the schema. Each old address 301s from `public/_redirects` (journal, shop and guides to `/`, quiz and calculator to `/services/`, press to `/about/`, gift certificates to `/contact/`, resources to `/faq/`), pinned by `src/lib/retired-redirects.test.ts`, and the eight slugs stay in `RESERVED_SLUGS` so a custom page can never sit behind a redirect. Fields on KEPT types that only served them are hidden + read-only, never deleted: `siteSettings.newsletter`, the eight retired `sectionVisibility` switches, and `homePage.featuredJournal*`. The home `featuredJournal`/`press` and About `press` layout-marker values also stay in the schema, titled "(retired, renders nothing)", because Sanity turns an `options.list` into a hard `valid()` rule and deleting them would make the rows already stored on those pages block publishing; the renderers draw nothing for them.

Studio plumbing, added 2026-08-28. All SSR (`prerender = false`), all `noindex`, none of them in the sitemap:

| Path                      | Source                                                | Notes                                                                                                                                                                                                                                                                                                        |
| ------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/studio/*`               | `@sanity/astro` integration + root `sanity.config.ts` | The embedded Sanity Studio. Rebuilds with every deploy, so it cannot drift stale. One prerendered page at `/studio/` that routes on the URL hash; path-style deep links are proxied to it by `public/_redirects` and moved into the hash by `src/sanity/lib/studio-deep-link.ts`                             |
| `/preview/[...slug]`      | `src/pages/preview/[...slug].astro`                   | Draft-aware render of any page for the Presentation tool. Builder pages preview through their real renderer; bespoke pages preview their editable surface with a note saying so; projects (`/preview/portfolio/<slug>`) through the same `src/components/detail/ProjectDetail.astro` body the live page uses |
| `/preview/live`           | `src/pages/preview/live.ts`                           | SSE proxy over Sanity's listen API so the preview auto-refreshes. 403 without the Studio cookie. Event-driven, never a poll                                                                                                                                                                                  |
| `/api/draft-mode/enable`  | `src/pages/api/draft-mode/enable.ts`                  | Validates Sanity's one-time preview secret and sets the perspective cookie. 401 on a bad secret                                                                                                                                                                                                              |
| `/api/draft-mode/disable` | `src/pages/api/draft-mode/disable.ts`                 | Clears the cookie. The "Exit preview" link target                                                                                                                                                                                                                                                            |
| `/api/stats`              | `src/pages/api/stats.ts`                              | JSON for the Studio "Site stats" tool: 28 days of page views + visitors from Cloudflare's zone analytics. Gated by the preview cookie's VALUE (`isStudioPreview`), never its presence. 503 "unconfigured" until `CF_ANALYTICS_TOKEN` exists                                                                  |
