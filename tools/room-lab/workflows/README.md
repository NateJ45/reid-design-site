# ComfyUI workflows

`generate.mjs` loads ComfyUI workflows in **API format** (ComfyUI menu: Workflow > Export (API)) from this folder:

- `t2i.json`: text to image, makes the empty room (base).
- `edit.json`: instruction edit (Qwen-Image-Edit-2511), makes each later stage from the previous frame. The default for `stages` and `probe`.
- `edit-reflatent.json`: the edit variant that feeds a full-resolution reference latent. Choose it with `--workflow edit-reflatent`; each attempt records which workflow it used in `work/run.log.json`.

Compare the two edit variants with `npm run room:generate -- probe --image <png> --change "<text>" --seed <n> --workflow <name>`, which runs one edit and prints the drift numbers.

They are not generated by this kit. When exporting a new one from ComfyUI, put the placeholder tokens below where the value belongs.

## Token contract

`generate.mjs` deep-walks the JSON and replaces every string value that is exactly one of these tokens:

| Token            | Replaced with                                | Type   | Used in   |
| ---------------- | -------------------------------------------- | ------ | --------- |
| `"__PROMPT__"`   | positive prompt (edit: instruction + change) | string | both      |
| `"__NEGATIVE__"` | negative prompt                              | string | both      |
| `"__SEED__"`     | integer seed                                 | number | both      |
| `"__WIDTH__"`    | frame width (1472)                           | number | both      |
| `"__HEIGHT__"`   | frame height (1104)                          | number | both      |
| `"__IMAGE__"`    | name of the uploaded previous frame          | string | edit only |
| `"__PREFIX__"`   | SaveImage filename_prefix                    | string | both      |
| `"__DENOISE__"`  | the piece's `denoise` (0 to 1, default 1)    | number | edit only |

A piece in the room spec may set `workflow` (a name from this folder, beating the `--workflow` default for that piece) and `denoise` (0 to 1). `__DENOISE__` is optional: a workflow without the token ignores `denoise`.

The workflow must end in a SaveImage (or PreviewImage) node; the first output image is used. If the model returns a different size the script resizes it to width x height and warns.
