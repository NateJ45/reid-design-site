# Security policy

## Supported versions

Only the current `main` branch is supported. It is what runs at [reiddesignllc.com](https://reiddesignllc.com).

## Reporting a vulnerability

Please report security problems privately by email to **nathan@nixoncreativestudio.com**. Do not open a public issue or pull request for a vulnerability.

Include what you found, where, and the steps to reproduce it. You can expect an acknowledgement within a few days. Once a fix is live, the report can be discussed publicly if you wish.

This is a small business marketing site. The only form posts to a third-party form service, and there is no customer account system, so the most useful reports concern the contact form, the embedded Sanity Studio at `/studio`, and the preview routes.
